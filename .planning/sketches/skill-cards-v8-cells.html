How the references actually do it

None of them typeset facts as prose. Perplexity's answer surface is a stack of typed components: a source-chip row, the answer, then related questions as tappable hairline-separated cells. ChatGPT renders canvases and attachments as cards with an icon tile, a title and a one-line subtitle. Claude shows artifacts the same way: tile, title, metadata line. The shared primitive is the cell: icon + title + subtitle, separated by hairlines. Text lives inside components; it is never loose on the surface.

v8 applies exactly that primitive. The card becomes a header bar, a hero, a media panel, and then cells. The critical difference from every rejected round: the cell title is extracted from the content — "Crash-zoom", "Pattern-interrupt", "34% of your audience" — never a category label like VISUAL or TOPIC. The subtitle is one line, full stop. On mobile the panel collapses into a strip cell (thumbnail + title, like a Perplexity source card) and the whole card is a clean cell list; nothing floats, nothing wraps around anything.

The no-video question has a clean answer: the first-frame panel renders from hookLine, which always exists, so direction A has no empty state. The source cell and the audience cell simply disappear when a run is ungrounded or uncalibrated; the card below shows that state and it still reads designed.
