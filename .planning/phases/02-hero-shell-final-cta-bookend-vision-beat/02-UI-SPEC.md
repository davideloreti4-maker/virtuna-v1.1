### Coral single-stop rule (MOTION-03)

When coral appears as a tint/gradient (Spotlight, BorderBeam glow), it MUST be a single-stop alpha gradient:
- Valid: `rgba(255, 127, 80, 0.15)` — one stop, alpha-only
- Invalid: `linear-gradient(to bottom, #FF7F50, #FF3F20)` — multi-hue, forbidden

## Spotlight Contract (HERO-04, MOTION-03)

Aceternity `Spotlight` component — coral-tinted single-stop alpha gradient backdrop.

| Property | Value | Rationale |
|----------|-------|-----------|
| Component | Aceternity `Spotlight` | Via shadcn CLI install at plan time |
| Fill color | `rgba(255, 127, 80, 0.12)` | Single-stop coral alpha — 12% opacity keeps text contrast ≥ 4.5:1 |
| Position | `top: -20%; right: -10%` (desktop) | Top-right origin, matches Linear/Raycast ambient gradient convention |
| Size | `800px × 600px` ellipse | Wide enough to tint above-fold without overwhelming |
| Blend mode | `normal` (no blend mode override) | Blend modes interact unpredictably with dark bg; plain alpha is sufficient |
| Reduced-motion | Spotlight rendered statically (no CSS animation if Aceternity adds one) | Manual `useReducedMotion()` guard required — Aceternity does not inherit MotionConfig |

| Shared usage | Same component instance pattern used in Final CTA section | Identical props — bookend symmetry locked |
| WCAG AA check | H1 text (#f9f9f9) on coral-tinted bg: contrast must remain ≥ 4.5:1 | Verified: #f9f9f9 on rgba(255,127,80,0.12) blended over #07080a ≈ bg #14100d → ratio ~14:1 ✓ |

Implementation note: Aceternity Spotlight applies `backdropFilter` — wrap in inline `style` if Lightning CSS strips it (per MOTION-04 guardrail).

## WordRotate Contract (HERO-09, MOTION-01, MOTION-02)

Magic UI `WordRotate` — single rotating word slot fused inside the H1 sentence.

| Property | Value |
|----------|-------|
| Component | Magic UI `WordRotate` (install: `npx shadcn@latest add @magicui/word-rotate`) |
| Word cycle | `["creators", "brands", "founders"]` — D-02 locked |
| H1 sentence | `Predict viral for [WordRotate] before you post.` — D-01 locked |
| Rotation interval | `2500ms` (2.5 seconds per word) — from `motionTokens.durations` convention; long enough to read, short enough to feel alive |
| Transition duration | `400ms` — `motionTokens.durations.slow` (0.3s) rounded up for legibility |
| Transition easing | `motionTokens.easings.outQuart` → `cubic-bezier(0.165, 0.84, 0.44, 1)` |
| Transition type | Vertical slide-up with fade: outgoing word slides up + fades out, incoming word slides up into position + fades in |
| Left-edge alignment | `display: inline-flex; min-width: [longest-word-width]px` — width locked to "creators" (longest word at H1 font-size) so the sentence never reflows when the word changes |
| Longest word budget | "creators" at 64px/700 weight ≈ 290px desktop, ≈ 180px mobile — measure at plan time with canvas or CSS font-metrics |
| Reduced-motion fallback | Static word: `"creators"` (first in array, covers broadest audience). WordRotate stops all animation; word is frozen. MotionConfig `reducedMotion="user"` kills `motion/react` transitions; WordRotate must also check `useReducedMotion()` for its CSS interval timer |
| IntersectionObserver gate | WordRotate only starts cycling once Hero section enters viewport (`threshold: 0`, `rootMargin: "0px"`) — MOTION-02 compliance. On re-enter: resume from current word (do NOT restart from index 0) |
| DOM structure | `<h1>Predict viral for <span className="inline-flex min-w-[{creators-width}]"><WordRotate .../></span> before you post.</h1>` — span stabilizes layout |
| Screen reader | Wrap WordRotate in `<span aria-live="off" aria-atomic="true">` — word changes should NOT be announced (too distracting). Static `aria-label` on `<h1>` provides full sentence for screen readers: `aria-label="Predict viral for creators, brands, and founders — before you post."` |

## Reduced-Motion Policy (MOTION-01, HERO-07)

Phase 2 has three animation systems. Each must be independently gated.

| Animation | `prefers-reduced-motion: reduce` behavior | Implementation |
|-----------|------------------------------------------|----------------|
| WordRotate cycling | Static "creators" — no rotation, no slide transition | `const prefersReduced = useReducedMotion()` from `motion/react`; if true, render static `<span>creators</span>` in place of `<WordRotate>` |
| ShimmerButton shimmer | `animation: none` — button renders with static coral border + dark bg | CSS: `.shimmer-button { @media (prefers-reduced-motion: reduce) { animation: none; } }` or inline conditional |
| BorderBeam on ShimmerButton | Do not render `<BorderBeam>` — skip entirely | Conditional render: `{!prefersReduced && <BorderBeam ... />}` |
| AnimatedShinyText shimmer | Static text, no shimmer sweep | Same `useReducedMotion()` conditional |
| Spotlight | Render statically (no CSS animation if Aceternity adds `@keyframes`) | Manual `useReducedMotion()` guard |
| Hero/Final CTA entrance | No `motion.div` fade-in — render immediately | MotionConfig `reducedMotion="user"` handles all `motion/react` components automatically |
| Vision Beat | No motion — static by design | Safe |

**Aceternity + Magic UI components** do NOT inherit `MotionConfig reducedMotion="user"`. Every component in this phase that uses its own CSS animation or JS timer must be independently guarded with `useReducedMotion()` from `motion/react`.

## IntersectionObserver Autoplay Gate (MOTION-02)

All animations that "play" (WordRotate cycling, BorderBeam, Spotlight if animated) must be gated on viewport entry.

| Animation | Threshold | rootMargin | Re-enter behavior | Reduced-motion |
|-----------|-----------|------------|-------------------|----------------|
| WordRotate interval timer | `0` (any pixel visible) | `"0px"` | Resume current word index — do NOT reset to 0 | Stop entirely |
| BorderBeam | `0.1` (10% visible) | `"0px"` | Do not restart — `triggerOnce: true` per `motionTokens.triggerOnce` | Do not render |
| ShimmerButton shimmer | CSS animation — starts on mount, no IO gate needed (it's a CSS loop) | n/a | Always running when mounted | `animation: none` |
| Spotlight | Render on mount (above fold — IO gate not needed; it's static visual, not looping animation) | n/a | n/a | Static render |

WordRotate IO implementation:
```tsx
const ref = useRef<HTMLSpanElement>(null);
const [inView, setInView] = useState(false);
useEffect(() => {
  const obs = new IntersectionObserver(([e]) => setInView(e.isIntersecting), {
    threshold: 0,
    rootMargin: "0px",
  });
  if (ref.current) obs.observe(ref.current);
  return () => obs.disconnect();
}, []);
// Pass inView to WordRotate to pause/resume interval
```
