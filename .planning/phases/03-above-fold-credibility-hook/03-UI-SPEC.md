## Spacing Scale

Standard 8-point scale inherited from globals.css `@theme` spacing tokens.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline divider gaps |
| sm | 8px | Logo slot gaps (mobile row) |
| md | 16px | Microcopy margin-top, logo bar horizontal padding |
| lg | 24px | Logo bar vertical padding (desktop) |
| xl | 32px | Max gap between CTAs and logo bar |
| 2xl | 48px | — |
| 3xl | 64px | Desktop placeholder gap reserved in HeroBookend (hidden md:block min-h-[64px]) |

**Critical constraint:** The credibility hook must occupy the 64px desktop gap already reserved by `HeroBookend`'s `<div className="hidden md:block min-h-[64px]" aria-hidden="true" />`. Phase 3 replaces that placeholder with the real component — no additional space may be added or the above-fold constraint breaks.

Mobile exception: gap collapses to 0 on mobile (`< md`); logo bar tucks between CTA pair and bottom viewport edge within `min-h-[100dvh]`. Logo bar height on mobile must stay ≤ 48px.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#07080a` (`--color-background`) | Hero section background, logo bar background |
| Secondary (30%) | `#18191a` (`--color-surface`) | Placeholder logo slot bg |
| Accent (10%) | `#FF7F50` (`--color-coral-500`) | Numen Machines lockup text or thin left-border rule on Numen slot ONLY |
| Destructive | n/a | No destructive actions in this phase |

**Accent reserved for:** Numen Machines slot only (single thin coral left-border `border-l border-l-coral-500/40` OR coral tint on the Numen Machines wordmark). No other element in the credibility hook uses coral.

**Logo slot treatment:**
- Background: `rgba(255,255,255,0.02)` (below card hover bg — intentionally invisible)
- Border: `rgba(255,255,255,0.06)` (6% white — universal Raycast border rule)
- Border-radius: 8px (input/button scale per CLAUDE.md)
- Placeholder slot content: muted text "Partner" at `text-foreground-muted` opacity 0.5

**No glow. No tint. No colored backgrounds.** Raycast rule: color only for accent element.

## Component Anatomy

### CredibilityHook (new server component)

Location: `src/app/(marketing)/_components/CredibilityHook.tsx`

Renders INSIDE HeroSection, replacing the placeholder gap div. HeroBookend must be refactored to accept `credibilityHook` slot OR CredibilityHook is injected below HeroBookend and above the CTA pair within HeroSection's layout.

**Preferred injection point:** Between CTA pair and bottom of HeroSection — NOT inside HeroBookend (avoids HeroBookend becoming a god component). HeroBookend's `hidden md:block min-h-[64px]` placeholder div is removed; CredibilityHook takes that space.

**Structure (desktop, 1440px):**
```
[separator line — 1px rgba(255,255,255,0.06) full width]
[row: logo-slot × 5 + microcopy]
  logo-slot-1: Numen Machines (coral left-border accent)
  logo-slot-2..5: Placeholder "Partner" slots
  microcopy: "Backed by behavioral research · Numen Machines"
```

**Structure (mobile, 375px):**
```
[microcopy — centered, full width]
[row: logo-slot × 3 visible, overflow hidden or scrollable]
```

**Desktop logo bar dimensions:**
- Bar height: 64px total (matches reserved gap)
- Logo slot size: 40px height, variable width (min 80px, max 120px)
- Slot gap: 8px
- Numen Machines slot: 120px wide (text lockup, not raster)
- Separator line: 1px, `rgba(255,255,255,0.06)`, `margin-bottom: 16px`

**Mobile logo bar dimensions:**
- Bar height: max 48px
- Show 3 slots only (Numen + 2 placeholders) — others `hidden`
- Microcopy above logos, `text-center`

## Interaction Contract

### Static (no JS required)

The credibility hook is a **server component** — zero client JS. No animation on mount.

### Reduced Motion

Not applicable — no animation to suppress. Component renders identically under `prefers-reduced-motion: reduce`.

### Hover States

- Logo slots: `hover:bg-white/[0.04]` — the same step up as Raycard hover (`bg-white/[0.02]` → `bg-white/[0.04]`)
- Transition: `transition-colors duration-150`
- No translate-y, no border change — Raycast card hover rule

### Focus / Keyboard

- Logo slots are `<div>` elements with no interactive role (display only, placeholder)
- Numen Machines slot: if linked, `<a href="https://numenmachines.com">` with `focus-visible:outline-2 focus-visible:outline-coral-500/60 focus-visible:rounded-[8px]`
- Microcopy "Numen Machines" text: same link treatment if Numen slot is linked

### Screen Reader Order (HERO-10, HERO-11)

Reading order must be: H1 → sub-headline → CTA pair → credibility hook.

`CredibilityHook` renders AFTER the CTA pair in DOM order — matches visual order. No `aria-hidden` on the hook itself.

```html
<section aria-label="Backed by">
  <p aria-label="Numen Machines logo" role="img">Numen Machines</p>
  <p aria-label="Partner placeholder slot 1" role="img" aria-hidden="true"></p>
  <!-- ... -->
  <p>Backed by behavioral research · Numen Machines</p>
</section>
```

Placeholder slots: `aria-hidden="true"` (no meaningful content).
Numen Machines slot: descriptive `aria-label="Numen Machines — product studio behind Virtuna"`.
