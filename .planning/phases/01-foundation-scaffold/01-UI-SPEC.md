## Typography

Pre-populated from `globals.css`. Phase 1 uses 4 sizes and exactly 2 weights.

**Weight constraint:** Phase 1 uses only `--font-regular` (400) and `--font-semibold` (600). Tokens `--font-medium` (500) and `--font-bold` (700) exist in `globals.css` but are NOT used in Phase 1 — reserved for Phase 2+ where section content may justify them. Matches Raycast weight restraint (soft over heavy).

| Role | Size | Weight | Line Height | Letter Spacing | Usage |
|------|------|--------|-------------|----------------|-------|
| Body | 16px (`--text-base`) | 400 (`--font-regular`) | 1.5 (`--leading-normal`) | 0.2px | Section placeholder label text |
| Label / Nav | 14px (`--text-sm`) | 400 (`--font-regular`) | 1.25 (`--leading-snug`) | 0.2px | Header nav links, section anchor labels |
| Section Heading | 30px (`--text-3xl`) | 600 (`--font-semibold`) | 1.1 (`--leading-tight`) | -0.02em (`--tracking-tight`) | Section placeholder H2 labels |
| Display / Logo | 16px (`--text-base`) | 600 (`--font-semibold`) | 1 | 0 | Virtuna wordmark in header |

Phase 1 does NOT use `--text-hero` (52px) or `--text-display` (64px) — those belong to Phase 2 Hero shell.

Font rendering: `antialiased` (`-webkit-font-smoothing: antialiased`) — confirmed in `globals.css` base styles.

## Color

Pre-populated from `globals.css` semantic token layer.

| Role | Value | Token | Usage |
|------|-------|-------|-------|
| Dominant (60%) | `#07080a` | `--color-background` / `--color-gray-950` | Page background, section shells |
| Secondary (30%) | `#1a1b1e` | `--color-background-elevated` / `--color-gray-900` | Section placeholder card surfaces, header blur surface |
| Accent (10%) | `#FF7F50` (coral) | `--color-coral-500` / `--color-accent` | Reserved-for list below |
| Destructive | none in Phase 1 | n/a | No destructive actions in Phase 1 |

**Accent reserved for (Phase 1 scope only):**
- "Sign up" CTA button in `LandingHeader.tsx` (background fill)
- Active anchor link indicator in header (underline or dot, 2px)
- Skip-to-content link focus ring (2px coral outline)

**NOT used for:** placeholder section labels, borders, nav "Sign in" link, sitemap/robots output (those are all `--color-foreground` or `--color-foreground-muted`).

Coral usage rule (from REQUIREMENTS.md MOTION-03): single-stop alpha gradient only when used as ambient tint — never multi-hue. Phase 1 header uses solid `coral-500` on CTA fill, not gradient.

**Grain overlay (POLISH-01):**
- Static SVG noise texture, `pointer-events: none`, `position: fixed`, `inset: 0`, `z-index: 0`
- Opacity: `0.03` (3%) on `--color-foreground` (white grain on dark bg) — barely perceptible, Linear/Raycast pattern
- Covers entire viewport; sits below all content (`z-index: -1` relative to page content)
- No CSS `backdrop-filter` (Lightning CSS strips it) — pure SVG `feTurbulence` filter or pre-generated SVG data URI

**Border color:** `rgba(255, 255, 255, 0.06)` (`--color-border`) — universal 6% rule from Raycast design language

**Header surface:**
- Background: `rgba(7, 8, 10, 0.85)` (`--color-background` at 85% alpha)
- Blur: applied via React inline `style={{ backdropFilter: 'blur(12px)', WebkitBackdropFilter: 'blur(12px)' }}` — NOT via Tailwind class (Lightning CSS strips `backdrop-filter`)
- Border-bottom: `1px solid rgba(255, 255, 255, 0.06)` (`--color-border`)

## MotionConfig Root Contract

Per FOUND-09 / MOTION-04: single `MotionConfig` wraps all 9 section shells.

```tsx
// src/app/(marketing)/v3/page.tsx (server component wrapping client MotionConfig island)
import { MotionConfig } from 'motion/react';

<MotionConfig reducedMotion="user">
  {/* 9 SectionShell instances */}
</MotionConfig>
```

`reducedMotion="user"` — reads OS preference via `prefers-reduced-motion` media query. Single kill-switch for all `motion/react`-powered animations across all phases.

Import path: `motion/react` (NOT `framer-motion`) — enforced from Phase 1 onward.

## motionTokens.ts Contract

Per POLISH-07: shared constants file installed in Phase 1, consumed by all section animations in later phases.

```typescript
// src/app/(marketing)/motionTokens.ts
export const motionTokens = {
  durations: {
    fast: 0.15,       // 150ms — micro-interactions
    normal: 0.2,      // 200ms — default transitions
    slow: 0.3,        // 300ms — section reveals
    slower: 0.5,      // 500ms — stagger parents
    hero: 0.8,        // 800ms — hero entrance
  },
  easings: {
    outCubic: [0.215, 0.61, 0.355, 1] as const,
    outQuart: [0.165, 0.84, 0.44, 1] as const,
    inOut: [0.42, 0, 0.58, 1] as const,
    spring: [0.34, 1.56, 0.64, 1] as const,
  },
  staggerDelays: {
    children: 0.08,   // 80ms between staggered children
    tight: 0.04,      // 40ms for dense lists
    wide: 0.15,       // 150ms for dramatic reveals
  },
  viewportThresholds: {
    default: 0.2,     // 20% of element in view before trigger
    hero: 0,          // Hero fires immediately (above fold)
    early: 0.1,       // 10% — large section blocks
    late: 0.4,        // 40% — small elements needing scroll commitment
  },
  triggerOnce: true,  // All animations fire once per session (BRAND-BIBLE VIZ-02)
} as const;
```

## Tailwind v4 Guardrails (from CLAUDE.md + STACK.md)

These guardrails apply from Phase 1 and cascade to all phases.

| Rule | Detail |
|------|--------|
| oklch L < 0.15 | Use hex, not oklch — Tailwind v4 compiles dark oklch inaccurately. Affected tokens: `--color-gray-950` (`#07080a`), `--color-surface` (`#18191a`), `--color-surface-elevated` (`#222326`). All are already hex in `globals.css`. |
| `backdrop-filter` / `mask-image` | Apply via React inline `style={{ backdropFilter: '...' }}` — Lightning CSS strips these from Tailwind classes. Header blur uses this pattern. |
| Dev cache | When CSS keyframe additions in `globals.css` don't render: kill dev server + clear `.next/` + `node_modules/.cache/` + browser cache. |
| `motion/react` imports | Never `framer-motion`. Lint or grep-check before PR. |
