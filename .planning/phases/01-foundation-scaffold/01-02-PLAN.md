    Per UI-SPEC § Grain Overlay Contract:
    - Element wrapper: `<div aria-hidden="true" className="fixed inset-0 pointer-events-none">`
    - z-index: `-1` (sits behind content; UI-SPEC says "below all content")
    - Opacity: `0.03` applied to the SVG element (not the wrapper, so the wrapper can stay at full opacity for layout)
    - SVG content: 100% × 100% viewBox with a `<defs><filter id="grain"><feTurbulence type="fractalNoise" baseFrequency="0.65" numOctaves="3" stitchTiles="stitch"/><feColorMatrix type="saturate" values="0"/></filter></defs>` and a `<rect width="100%" height="100%" filter="url(#grain)"/>`

    Concrete JSX (write exactly this shape):
    ```tsx
    export function GrainOverlay() {
      return (
        <div
          aria-hidden="true"
          className="fixed inset-0 pointer-events-none"
          style={{ zIndex: -1 }}
        >
          <svg
            className="w-full h-full"
            xmlns="http://www.w3.org/2000/svg"
            style={{ opacity: 0.03 }}
          >
            <defs>
              <filter id="virtuna-grain">
                <feTurbulence
                  type="fractalNoise"
                  baseFrequency="0.65"
                  numOctaves="3"
                  stitchTiles="stitch"
                />
                <feColorMatrix type="saturate" values="0" />
              </filter>
            </defs>
            <rect width="100%" height="100%" filter="url(#virtuna-grain)" />
          </svg>
        </div>
      );
    }
    ```

    Notes:
    - `aria-hidden="true"` per UI-SPEC § Grain Overlay (decorative, not in accessibility tree).
    - `pointer-events-none` per spec — never intercepts clicks.
    - `style={{ zIndex: -1 }}` (inline, NOT a Tailwind utility) — z-index -1 ensures it sits behind ALL page content including the page body. Avoids needing a custom Tailwind utility.
    - `style={{ opacity: 0.03 }}` (inline) — the 3% opacity value per UI-SPEC § Color > Grain overlay (POLISH-01).
    - Pure SVG `feTurbulence` filter — no mask-image, no backdrop-filter, so Lightning CSS does not strip it (per PITFALLS.md Pitfall 2 — safe path).
    - Single export only: `GrainOverlay`. No props.
    - Filter id is namespaced (`virtuna-grain`) to avoid collision if another SVG filter on the page uses `id="grain"`.

    Implements POLISH-01.

| T-01-08 | T (Tampering) | Shell components without "use client" | mitigate | Server-rendered = no client JS shipped for these three components. No XSS surface from props (all props typed; no `dangerouslySetInnerHTML`). |
