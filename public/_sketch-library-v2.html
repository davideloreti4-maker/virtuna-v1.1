UX audit applied

Projects over a repaired save loop. Rev 2 fixes what the audit found — including three places rev 1 contradicted the shipped design system, and four defects inherited from the current shelf. Tokens below are copied exactly from globals.css; cards are darker than the page (#1a1a19 on #1f1f1e), controls lighter (#2c2c2b).

Audit — findings and resolutions

rev 1Accent bookmark on every shelf card. Everything on the shelf is saved by definition, so it carried no information — and it spent the accent, which globals.css reserves for liveness, on decoration. Dropped from shelf cards. Remove lives in the ⋯ menu (already built: DotsThree + AlertDialog). The bookmark stays in-thread, where it means something.
rev 1Generic “Use in thread” primary button — a regression. The shipped card already has type-specific forward actions. Restored the real labels from saved-item-card.tsx:46 — “Write script →” (hook), “Develop into hooks →” (idea), “Test full script →” (script).
rev 1Wrong surface direction + invented band green. Rev 1 drew cards lighter than the page and used #8fbf7f. Cards #1a1a19 (darker), controls #2c2c2b (lighter), active facet darker with an inset top highlight. Band = --color-success/warning/error.
inheritedMasonry breaks reading order. CSS multicol fills top→bottom per column, so under “Recent” the 2nd newest sits below the newest, not beside it. The sort control silently doesn’t do what it appears to. Worse at xl:columns-4. Row-major CSS grid. Ragged bottom edges are the honest trade for order that matches the sort. 2 columns at 880px (~420px cards) instead of 3–4 (~200px, too narrow for a script).
inheritedNo bulk selection. The whole premise is “too much output to organize”; filing 60 items one at a time through a popover fails that premise. Screen 02: click-to-select, shift-range, a selection bar with Move to ▾ / Remove. This is the core interaction of the rework.
rev 1Hover actions grew the card inside a multicol flow — the card under the cursor would shift as the column reflowed. Checkbox and ⋯ are absolutely positioned; the kicker indents to make room. Zero height change on hover.
rev 1Search and sort had undefined scope — one header control sitting above two sections. Screen 05: typing switches to a global results mode; every result is badged with its project or “Unfiled”.
rev 1Projects grid ate the fold — 3-up cards with fake video thumbnails. At 8 projects you’d see no output at all, and most projects contain no video. Full-width compact rows: name · type mix · count · updated. Scales to 20 projects, no fake art, one “＋ New project” affordance (the duplicate is gone).
rev 1“Last-used destination” would silently file a hook from an unrelated thread into a project you touched weeks ago. Thread-aware default: if this thread already feeds a project, that one wins (badged “this thread”), else Unfiled. Uses the thread_id the loop fix now writes.
rev 1No empty states — yet zero projects and ~10 items is where every existing user starts. Screen 04. The Projects section never renders as an empty grid; it degrades to one quiet inline row.
rev 1Provenance footer was two lines of chrome competing with the content it describes. One muted line, relative time, whole line is the link, truncates: “from Hook ideas · 4d”.
rev 1Type chip repeated under a single-type facet, and project detail needed facets at all. Project detail groups by type instead (screen 03) — the grouping replaces the filter, and matches how a video gets built: hooks → scripts → the read.
