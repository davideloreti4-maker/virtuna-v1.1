## How a station runs

1. I state what the station is and what "correct" looks like.
2. You drive the browser and report what you actually see (screenshot or description).
3. I read the code/DB/network behind it in parallel and confirm or contradict.
4. Every gap becomes a numbered finding below. We do **not** fix it. We move on.

A station is DONE when every element on it has been either ticked or turned into a finding.

## Finding format

```
### F-NNN · <one-line claim>
- **Station:** A2 · **Kind:** BACKEND | UI | UX | DATA-HONESTY | PERF | COPY
- **Severity:** blocker | major | minor | polish
- **Saw:** what actually happened
- **Expected:** what should happen, and on whose authority (spec / owner call / design system)
- **Evidence:** file:line, network call, DB row, screenshot path
- **Repro:** exact steps
```

Severity rubric — *blocker* = cannot ship, path is broken or lies to the user. *major* = ships but
visibly wrong / dishonest / dead-end. *minor* = noticeable, not damaging. *polish* = craft debt.
