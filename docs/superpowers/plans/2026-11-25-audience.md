# Audience: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. One task per
> implementer, a failing test first for every behaviour, a review after each task.

**Goal:** under the new look, `/audience`, `/audience/[id]` and `/audience/new` become one page about the
audience Maven simulates for: the ring of 1,000 viewers in ten groups, where that picture came from, the
account's figures, what the read wrote, the videos Maven read, and one button to simulate a video for
them; a switch between the creator's audiences in the title; a new audience built in place. Spec:
`docs/superpowers/specs/2026-11-25-audience-design.md` (read it first; it wins over this plan where they
differ, and the controller's `.superpowers/sdd/2026-11-25-audience/rulings.md` wins over both). Drawing
(made-up sizes, real copy): `.scratch/next-look/part8/discover-audience/drawing/part-audience.png` and the
right half of `part-desktop.png`. Facts with file and line: `seam-map.md` (1.4 to 1.7, 2.2, 3, 4) and
`wiring-facts.md` (A, B, D, E) in `.scratch/next-look/part8/discover-audience/`.

**Shape:** no table, no column, no API route, no package. A pure module `src/lib/audience-next/` (the
page's model, its words, the stream reader, the building state) and one server read that takes the
existing repository functions as a parameter; the screen and its parts in
`src/components/audience-next/`; one client hook module `src/hooks/queries/use-audience-next.ts` over the
existing routes; the three route files branch on `NEW_LOOK_ENABLED`; a dev preview `/dev/audience`.

**Stack:** Next.js 16, TypeScript, Supabase, TanStack Query, Vitest (happy-dom, Testing Library,
vitest-axe), Tailwind v4.

```ts
export function kindOf(a: Audience, account: AccountRef | undefined): AudienceKind {
  if (account) return "own";
  if (a.calibration?.source === "scrape") return a.type === "personal" ? "own" : "other";
  return "described"; // never from signature.provenance.handle: a description stores its name there
}

export function groupsOf(a: Audience): { wedges: WedgeInput[]; groups: PageGroup[] } {
  const signed = a.signature?.audience.personas ?? [];
  const roster = signed.length > 0 ? signed : a.personas;
  // known archetype, first of each, finite share >= 0; sum <= 0 → { wedges: [], groups: [] }
  // sort: share desc, then ARCHETYPES order
  const wedges = rows.map((p) => ({ group: p.archetype, weight: p.share * 100, present: true }));
  const layout = ringDots(wedges, AUDIENCE_RING); // the ring's own counts: ring and text agree
  const groups = rows.map((p, i) => {
    const count = layout.wedges[i]!.dots.length;
    return { group: p.archetype, name: groupName(p.archetype), line: lineOf(blurbOf(p)), count,
             percent: Math.round(count / 10), judge: textOf(frameOf(p)), seen: textOf(evidenceOf(p)) };
  });
  return { wedges, groups };
}
```
