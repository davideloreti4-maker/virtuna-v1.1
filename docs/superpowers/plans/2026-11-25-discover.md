# Discover: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. One task per
> implementer, a failing test first for every behaviour, a review after each task. Tasks run in order,
> 1 to 7; a task touches only the files its **Files** list names.

**Goal:** under the new look, Discover is one place to find a proven video and make a version of it: the
hub at `/feed` with three chips (Videos, Collections, Watchlist), a page per video
(`/feed/video/[id]`), a page per collection (`/feed/collection/[slug]`), and the pull page
(`/feed/discover`). Spec: `docs/superpowers/specs/2026-11-25-discover-design.md` (read it first; it
wins over this plan where they differ, and the controller's
`.superpowers/sdd/2026-11-25-discover/rulings.md` wins over both). Drawing (made-up sizes, real copy):
`.scratch/next-look/part8/discover-audience/drawing/part-discover.png` and the left half of
`part-desktop.png`. Facts with file and line: `.scratch/next-look/part8/discover-audience/seam-map.md`
and `wiring-facts.md` (sections A, B, C, E).

**Shape:** no database change, no new package. Pure rules in `src/lib/discover-next/`; two reads in code
only (one library video with its beats; the watchlist's ids and covers); the screens in
`src/components/discover-next/`; the four existing route files branch on `NEW_LOOK_ENABLED`; two new
routes that are not found with the flag off; a dev preview `/dev/discover`; a small change to the frame
(`nav-config.ts`, `next-shell.tsx`) and to Library (a saved library video opens its page).

**Stack:** Next.js 16 (`params` and `searchParams` are Promises), TypeScript, Supabase, TanStack Query,
Vitest + Testing Library (happy-dom by pragma), Tailwind v4.

### The address

`/feed?tab=collections&niche=comedy&platform=tiktok&order=jump&q=meal`; defaults are left out (tab
`videos`, no niche, no platform, order `views`, empty q). `tab=outliers` (the old value) reads as
`videos`; an unknown tab, platform or order reads as its default; `niche` must match
`/^[a-z0-9-]{1,40}$/` and is read through `nicheKeyOf` (so `comedy-entertainment` reads as `comedy`);
`q` is trimmed and cut at 200 whole characters (`Array.from`, as `librarySearchText`). The hub writes
the address with `history.replaceState` (never a new entry), the way Library does
(`src/components/library-next/library-next.tsx:271-274`, `writeAddress`, and the seen/written pair at
`:498-560`): the view is read from `useSearchParams` (one source); the field's text is local and written
as `q` 250 ms after the last key; an address the screen did not write (the Discover tab, Back) is
followed, and the field takes its `q`.

Other addresses: `videoHref(id)` = `/feed/video/<id>`; `collectionHref({ slug, category })` =
`/feed/collection/<slug>?shelf=<category>` (a slug is unique only within its shelf: the table's key is
`(teardown_id, category, slug)`, `supabase/migrations/20260720120000_teardown_collections.sql:55`, and
`corpus-reads.ts:243-244` says one slug repeats across shelves; Question 2); `pullHref(input)` =
`/feed/discover?input=<encoded>`.

### Rules (pure, each with tests)

- **Niches** (`niches.ts`): `nicheKeyOf(raw)` trims and lowercases; `comedy` and
  `comedy-entertainment` are `comedy`; empty is null. `nicheLabel(key)` from this map, else the key with
  hyphens as spaces and a capital first letter: content-creation "Content creation", comedy "Comedy",
  self-improvement "Self-improvement", business "Business", tech "Tech", lifestyle "Lifestyle",
  health-fitness "Fitness", beauty-fashion "Beauty", education-science "Education", relationships-family
  "Family", food "Food", art-design "Art and design", travel "Travel", career "Career", sports "Sports",
  finance "Finance", other "Other". `nicheOptions(videos)`: the keys that have videos, most videos
  first, ties by label.
- **Grid** (`grid.ts`): `searchVideos(videos, q)`: empty q keeps all. A q that
  `classifyDiscoverInput` reads as a profile keeps the videos whose handle contains the normalized
  handle. Otherwise q is split on spaces and a video is kept when every word is in its text: the spoken
  line, the handle, "@"+handle, the raw niche, the niche's label, its formats (all lowercased).
  `filterVideos(videos, { niche, platform })`: niche by `nicheKeyOf(video.niche)`, platform by
  lowercase equality. `orderVideos(videos, order)`: a new array, never the input sorted in place;
  `views` views desc; `jump` the not-extreme first by multiplier desc, then the extreme ones, each by
  views desc; `newest` by `postedAt` desc, no date last; ties by id. `gridOf(videos, view, niches)`:
  search, then filter (a niche no video has reads as none), then order. `PAGE_SIZE = 24`.
- **Card** (`card.ts`): `cardLine(spokenHook)`: whitespace collapsed and trimmed; null when empty, when
  it holds no letter, when it holds a slot (`/\[[^\]]*\]|\{[^}]*\}|<[^>]*>/`), or when the whole line is a
  placeholder (`/^(?:n\/?a|none|null|undefined|untitled|no (?:spoken )?(?:hook|line|speech|audio)|music)$/i`;
  Question 10). `badgeOf(v)`: null unless `proven`; `100×+` when `extreme`; else `timesLabel(multiplier)`.
  `cardMeta(v)`: `@dev.lifts · 39.8M` (`viewsLabel`); no handle: `39.8M`. `cardName(v)`: the line, else
  `Video by @handle`, else `Video` (the accessible name of a card that shows no line).
- **The multiple's words** (`video-words.ts`): `multipleWords(v)`: null unless `proven`; else
  `{ text, shaky }`: `16× their average`, `8× their followers` or `16×` (the basis from `basisOf`), and
  for an extreme one `more than 100× their average` (or `… their followers`, or `more than 100×`) with
  `shaky: true`. `platformName(p)`: TikTok / Instagram / YouTube, else null. `watchLabel(p)`:
  `Watch on TikTok` …, else `Watch the original`. `videoMeta(v)`: `@nia.cooks · 25M views · TikTok · 2020`
  (a missing part is left out with its dot; the year from `postedAt` in UTC). `splitWhy(text)`: null for
  an empty text; else `{ lead, rest }`: the first two sentences (split after `.`, `!` or `?` followed by a
  space and a capital or an opening quote) and the rest, or `rest: null` when there is nothing more.
  `webAddress(value)`: an http(s) address or null (the rule of `library-next.tsx:181-190`).
- **Beats** (`beats.ts`): `beatsView(beats)`: null when no beat has a name. Beats with an empty name
  are dropped, the rest numbered from 1. Timed when every beat has a finite `startSec >= 0`, the starts
  never go down, and the last beat has a finite `endSec` above its start: then `length` =
  `clockWord(last endSec)`, `bar` = one share per beat ((next start, or the last end) minus its start,
  over (last end minus the first start); the shares add up to 1), each row `at` = `clockWord(startSec)`.
  Not timed: `length`, `bar` and every `at` are null. `clockWord(sec)`: whole seconds, `0:00`, `0:51`,
  `1:05`, `12:03`.
- **Saved videos** (`saved-ref.ts`): `isLibraryVideoRef(ref)` is the UUID form
  (`/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i`). `pulledVideoRef(platformVideoId)`
  = `tiktok:<id>`. `libraryVideoIdOf(item)`: the ref when `item_type === "outlier"`, `thread_id === null`
  and the ref is a library video's; else null. A library video is saved as `item_type "outlier"`,
  `ref_id` = its id, `thread_id` null, `title` = its card line (null when none), `snapshot`
  `{ caption: line ?? "", videoUrl, coverUrl, views, multiplier, baselineLabel, handle, platform }`
  (`buildRowVM` reads `caption`, `multiplier`, `baselineLabel`, `views`, `coverUrl`:
  `src/components/saved/saved-item-vm.ts:247-263`). A pulled video: the same with
  `ref_id = pulledVideoRef(…)`, so its mark survives a reload and Library opens its original.
- **Remix** (`remix.ts`): `REMIX_PLATFORMS = new Set(["tiktok", "instagram", "youtube"])`
  (Question 11; the controller's Remix check may narrow it to TikTok); `remixOffered(platform, videoUrl)`
  = platform in the set and `webAddress(videoUrl)` not null. `REMIX_BRIEF_MAX = 200` (a test asserts it
  equals `MAX_BRIEF` of `remix-brief-dialog.tsx`, imported in the test only). Prices from
  `creditCost("remix")` and `creditCost("discover")` (`src/lib/pricing.ts:130`), written with
  `creditsLabel` (`src/components/thread-next/answer-card.tsx`).
- **Return point** (`return-point.ts`, module memory): `leaveGrid({ href, shown, top })` when a card on
  the hub opens; `takeGrid(href, now?)` returns it once, only for the same address and within 30
  minutes. The hub, on mount, takes it: it shows that many cards and puts `<main>`'s scroll back (Library
  scrolls `<main>`, `library-next.tsx:116`).
- **Pull intent** (`pull-intent.ts`, module memory, as `src/lib/onboarding/pending-upload.ts` stages a
  file): `armPull(input, now?)` before a Pull button navigates; `takePull(input, now?)` is true once, for
  the same trimmed input, within `PULL_INTENT_MS = 15_000`. An address alone never carries it, so arriving
  by address never starts a pull.
