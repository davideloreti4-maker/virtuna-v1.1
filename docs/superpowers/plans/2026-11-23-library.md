# Library (part 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** With `NEXT_PUBLIC_NEW_LOOK` on, `/library` is one list of the creator's chats (each row says what is in it and how it did), filtered by All / Drafts / Simulated / Saved, searchable and paged, with rename, pin and delete on each row; Home's Recent rows use the same data.

**Architecture:** One pure function reduces a chat's messages and simulation records to a small summary; a new read-only endpoint returns a page of chats with that summary (no database change, heavy data stays on the server); a new folder `src/components/library-next/` holds the presentational screen and its container. `/library` branches on the flag in its route file; flag off keeps the saved shelf exactly as it is.

**Tech Stack:** Next 16, React 19, TypeScript, Tailwind v4, Supabase (server client), TanStack Query (`useInfiniteQuery`), Radix (the app's `Sheet`, dropdown and dialog parts), Vitest + happy-dom + Testing Library.

## Global Constraints

- Everything new is behind `NEW_LOOK_ENABLED` (`@/lib/flags/new-look`). Flag off must render and behave exactly as before: `/library`, `/library/[projectId]`, `/saved`, the saved shelf and every request. Never change a legacy class string, branch or request.
- **No database change.** No migration, no new column, no SQL function. Reads only, through the app's existing server client patterns.
- **Nothing in Library spends credits.** No control on this screen may call a paid route (`/api/tools/*`, `/api/analyze`). No "tap to simulate".
- Heavy data never reaches the browser: the endpoint's response holds no `population`, `personas`, `heatmap`, `verbatim` or message bodies.
- Numbers: a text's number is `stopNumberOf(seal)` (`src/lib/thread-next/stop-number.ts`), "would stop to watch"; a video's number is `headlineOf(audienceOf(...))` (`src/lib/result/headline.ts`), "watch to the end". Never another field.
- Copy, verbatim: "Library" · "All" · "Drafts" · "Simulated" · "Saved" · "Search" · "Show more" · "Nothing here yet." · "New chat" · "No drafts." · "Nothing simulated yet." · "Nothing saved yet. Save a hook or an idea from its details." · "No chat called "{query}"." · "Couldn't load your library." · "Try again" · "Rename" · "Pin" · "Unpin" · "Delete" · "Removed." · "Undo" · "Stage" · "Draft". Say "Simulate" / "simulated", never "Test". Sentence case, no uppercase labels, no em dashes.
- New-look code: colours only as tokens (`bg-surface`, `bg-surface-sunken`, `text-foreground`, `text-foreground-secondary`, `bg-action`, `text-action-foreground`, `border-border`); gauges ink only; no hex/rgb, no Tailwind palette colour, no `text-[Npx]`, no half-pixel sizes; shadows as `shadow-[var(--shadow-rest)]`, never the utility; no glass. Type roles: `text-meta` 13/18, `text-reading` 14, `text-ui` 15/21, `text-title` 16/22; the page heading alone `text-3xl`. Radii from the scale (`rounded-xl` 16, `rounded-2xl` 20, `rounded-3xl` 24, `rounded-4xl` 32, `rounded-full`).
- Every control has a name and a 44 px tap area (`tap-44` where drawn smaller). The global unlayered `:focus-visible` outline and `h1/h2/h3` letter-spacing beat utilities: set those with inline `style` when needed. Focus is never dropped on the page.
- Tests exercise real behaviour. Stand-ins only at I/O boundaries: `fetch`, the Supabase server client, the router, `matchMedia`, storage, time. Never a stand-in for our own modules. Write the test first and watch it fail.
- Do NOT commit, stash or push. Do not read `.env*`. Do not start a dev server unless the task says so (then `-H 127.0.0.1`, stop it after). The repo is public: no real ids, links, handles of real accounts or account data in code, tests, fixtures or docs (invented handles such as `@nia.tests`).
