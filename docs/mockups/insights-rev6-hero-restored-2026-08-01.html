Try this first

  1. Press “Trim 0:00–0:03” on Overview. It re-simulates: the answer becomes a before → after, the cortex repaints, the tiles move, and Engagement’s curve redraws against the old one. Undo puts it back.
  2. Switch to Audience or Engagement. Those pages carry no fix of their own, so the same button rides at the foot of the rail — and goes quiet the moment the fix is applied. The drill no longer dead-ends in an explainer.
  3. Open “How these numbers are made” at the bottom. The nine signals, the σ bars and the per-second grid live there now — demoted, not deleted.
  4. Tap a row in “What they did” on Audience to hear that segment speak.

Calls you may want to reverse

  • The hero now states the loss, not the keep. It read 38% · would stop over an answer saying “62% leave” — but CURVE[3]=.38 is who stays, and the room row means stopped scrolling. It now reads 62% · leave by 0:03.
  • Coral once per screen. The tiles, the insights and the dot rows gave it up; the answer block keeps it. Loss reads by position and weight instead.
  • The stat row is dimmed to 11.5px faint — projections for an unposted video should not be the loudest data on the page.
  • The primary button is cream-filled. The system says active is cream on a lighter fill, never coral — so the one action is the brightest object on the surface.
