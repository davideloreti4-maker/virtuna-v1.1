§11 · Deliberate limits

· Thumbnails are CSS stand-ins for the real source stills; the mock's brain is a stand-in for the existing WebGL cortex.

· No corpus multiplier until its basis is settled; view counts + sim scores only. "87% match" prints only from real reconciliations.

· Catalog routing (typed text → job) is a build-time producer; the catalog is the contract. Row order per workspace is a product call.

· Run provenance (audience/platform per run) still stamps every run in data; the thread shows it via the context bar.

· Generation never auto-simulates. The sim is fire-on-demand (a card's Simulate action, or the sub-bar door). Only the nightly drops arrive pre-scored — the proactive pipe ran them overnight. In-thread meters appear only after a fired run.

· Not drawn yet: the script view, the mobile nav drawer, Library, overnight-agent states. Next mock or build-time.
